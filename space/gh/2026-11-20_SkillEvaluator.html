1) 它是干什么的（说白了）

给"AI 技能包（Agent Skill）"做体检的。

现在很多 AI 助手（Claude Code、Codex、Cursor…）都支持装"技能包"——一个文件夹，里面写着"遇到什么情况该怎么做"。问题来了：这个技能包到底靠不靠谱？会不会泄密？会不会跟别的技能重复？装了以后真的让 AI 变强了吗？

SkillEvaluator 就是回答这四个问题的工具。就像体检中心： - 先查证件（格式对不对）； - 再查有没有病（安全、隐私、许可证）； - 再查是不是重复（和已有技能撞车）； - 最后上场实测（装着技能 vs 不装，任务成功率差多少）。

2) 它由哪几块组成（三层体检 + 一条流水线）

SkillEvaluator
 ├─ Tier 1 静态体检（不用模型、不用 GPU）
 │    schema / quality / security / PII / license /
 │    code-integrity / Unicode / script 检查
 │    + Harness Check：这个技能在各大 AI 助手里"能不能被加载"
 │    （安全扫描用 SkillSpector、Gitleaks、Bandit，可选 Semgrep）
 ├─ Tier 2 语义去重
 │    检测技能内部/之间内容重复、冗余
 ├─ Tier 3 真机评测
 │    同一任务跑两遍：带技能 vs 不带技能 → 算 "Skill Lift"
 │    （还包含合成评测数据集生成）
 └─ 外围：CLI + GitHub/GitLab CI + NVIDIA skills 目录

3) 核心机制（它是怎么做到的）

A. Tier 1：一堆"硬指标"先卡住 - 检查技能包的字段是否合规、描述是否超长、有没有脚本乱执行、有没有 PII（个人信息）、许可证是否缺失； - 还会做 Harness Check：把技能放进不同 AI 助手的加载器里试，看是否真的被读到。 - README 里就有真实例子：某个技能的 description 是 1028 个 UTF-16 单元，超过 1024 上限 4 个，导致 copilot-cli 直接不加载——这种坑人肉很难发现。

B. Tier 2：查"是不是抄的/重复的" - 语义层面比对，发现冗余内容，避免技能目录里一堆同质化条目。

C. Tier 3：唯一能回答"到底有没有用"的一层 - 同一个任务，带技能跑一遍、不带技能跑一遍，比较结果 → 得到 Skill Lift； - 还会自动生成合成评测数据集，减少人工出题。

D. 接进 CI - skillevaluator ci init 在仓库里生成配置，之后每次 PR 改动技能都会自动体检并出报告。

4) 一次使用流程（像去体检）

  1. 安装：pip install --upgrade skillevaluator
  2. 先做"无钥匙体检"：skillevaluator quality-check ./my-skill（不需要 API key、不需要 GPU、不需要 Docker）
  3. 看报告：分数 + 具体问题（哪条 schema 不合、哪个文件有 PII、描述超了几个字符）
  4. 深入：跑 Tier 2 去重、Tier 3 真机评测（需要模型/API key）
  5. 接 CI：skillevaluator ci init，以后每次改技能自动检查

5) 它比同类强在哪

  1. 分层设计：便宜的静态检查先跑，贵的模型评测后跑，省钱；
  2. Harness Check 很实用：直接告诉你"这个技能在 Claude Code 能加载、在 copilot-cli 加载不了"；
  3. 可量化：把"技能好不好"变成分数和 Skill Lift，而不是拍脑袋；
  4. 背靠 NVIDIA 目录：过了检查的技能会进入 NVIDIA Verified Skills 流水线；
  5. 门槛低：第一层完全免费、离线、无需模型。

6) 你可以怎么玩

  • 你自己写了一个 skill（比如给 Claude Code 用的），先跑： bash skillevaluator quality-check ./my-skill 这行就是"给它做一次基础体检"，会打印分数和问题清单。
  • 想接进 GitHub Actions：skillevaluator ci init，按提示选检查项即可。
  • 想评估"装了技能到底有没有用"，再上 Tier 3（需要模型 key）。

给你的建议：你日常在用各种 skill/技能包，先拿一个你常用的跑一次 quality-check，看看它的评分和问题列表——这是理解"技能质量"最直观的方式。

7) 一句话总结

SkillEvaluator = AI 技能包的体检中心：先查格式与安全（Tier 1）、再查重复（Tier 2）、最后用"带技能 vs 不带技能"的对照实验证明它真有用（Tier 3）。
