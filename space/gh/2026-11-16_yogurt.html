1) 它是干什么的（说白了）

开会的时候它帮你记笔记，而且全程不出你的电脑。

就像雇了一个坐在你旁边的速记员：你开会，它把你说的、别人说的都记下来，开完会还帮你写一份总结。但这个"速记员"不联网、不录音到云上，所有东西都存在你自己的电脑里。

它解决的问题：市面上的 AI 会议笔记（比如 Granola）都要把你的话传到云端，担心隐私；Yogurt 是免费、开源、全程本地的替代品。

2) 它由哪几块组成（像一家小公司）

┌─ 你看到的部分：一个桌面软件（Electron 画的界面）─────────┐
│                                                          │
│  🎙️ 录音员（whisper.cpp）                                │
│     把你说的话变成文字，像速记员听打                     │
│                                                          │
│  🧠 小助理（llama.cpp 本地模型）                          │
│     把记录整理成会议纪要，还能回答问题                   │
│                                                          │
│  🗄️ 仓库（本地文件夹）                                    │
│     录音、文字稿、笔记都存自己电脑                       │
│                                                          │
│  🔌 插座（MCP 服务器）                                    │
│     你自己的 AI 助手（如 Claude）想看笔记？从这里接      │
└──────────────────────────────────────────────────────────┘

三种"高科技"其实都是现成零件： - whisper.cpp：一个著名的"语音转文字"工具（像讯飞听打的开源版）； - llama.cpp：一个能在普通电脑上跑"本地小模型"的工具（不用联网）； - Electron：用网页技术做桌面软件的框架。

它聪明的地方不是发明技术，而是把零件组装得又稳又好用。

3) 核心机制（它是怎么做到的）

A. 怎么知道你开会了？ - 它会检查"现在是谁占着麦克风"：Zoom / Teams / 浏览器标签页标题 / 日历里的事件。 - 发现了就弹提示问你要不要录，不会偷偷录。 - 会议结束后自动停止录音。

B. 怎么把说话变成文字？ - 用 whisper.cpp 在本地转写。电脑配置差就先用小模型（约 5GB），配置好就用大模型（14GB 以上）。 - 多语言模式支持 99 种语言。

C. 怎么写总结、回答问题？ - 用 llama.cpp 跑本地开源模型（Gemma 4 / gpt-oss / Qwen3 家族），按你的电脑配置自动挑。 - 回答问题时会标出处（引用到具体会议的文字稿）。

D. MCP 插座的安全设计（很讲究） - 默认关闭，你在设置里手动开； - 打开后，别的 AI 程序只能读，不能改； - Mac/Linux 用文件权限 0600（只有你的账号能打开），Windows 用每次启动都换名字的"命名管道"——都是防别的程序乱碰。

4) 一次完整流程（像点外卖）

  1. 开会：软件提示"检测到 Zoom 会议，要录吗？"→ 你点"录"；
  2. 边说边记：麦克风 + 系统声音 → whisper.cpp → 文字一点点出现；
  3. 开完会：llama.cpp 本地模型 → 自动生成会议纪要（按人、按事项）；
  4. 会后提问："上次讨论的发布计划是什么？" → 它带着引用回答；
  5. 导出：复制笔记或保存成 Markdown 文件。

全程只有一件事联网：第一次下载 AI 模型（下载完就彻底离线）。

5) 它比同类强在哪

  1. 不用机器人入会：别的方案要拉一个机器人进会议（很尴尬），它直接录你电脑的声音；
  2. 隐私是默认的：不是"勾选隐私选项"，而是根本没联网的功能；
  3. 按配置选模型：不会让 8GB 内存电脑硬跑 14GB 模型；
  4. MCP 权限设计克制：只读 + 默认关 + 有限授权，比很多 AI 工具干净；
  5. 完全免费：没有账号、没有订阅。

6) 你可以怎么玩

  • 直接下载安装：Mac / Windows / Linux
  • 要求：8GB 内存以上，Windows 10 / macOS 14.4 / Ubuntu 22.04
  • 第一次启动会下载 AI 模型（约 5GB，电脑好的会下更大的），下载完就能完全离线用
  • 想折腾代码：仓库里有"本地构建"文档，需要会一点编程

给你的建议：如果你的电脑内存 ≥ 8GB，装一个试试"本地 AI"到底有多好用——这是感受"AI 不联网也能干活"的最简单方式。

7) 一句话总结

Yogurt = 用现成零件（whisper.cpp + llama.cpp + Electron）组装出的"本地速记员"：会议纪要、问答、导出全在本地完成，隐私不靠承诺靠架构。
