2) 逐项目要点回顾

① yogurt（11-16） 说白了就是"会议记录本自己会写"。它在你自己电脑上跑语音转写（Whisper）和大模型总结（llama.cpp），录音不出本机；用 Electron 打包成 Mac/Win/Linux 安装包；一周从 0 涨到 1.7k star，说明"隐私 + 本地 AI"是真需求。

② abyssal-garden（11-17） 一个反常识的炫技：96KB 代码（比一张照片还小）生成整片深海，用 WebGPU 实时渲染。巧思是"不存模型，只存规则"——靠数学函数现场生成地形与生物，所以体积极小。学习价值在渲染管线与程序化生成，对 DSH 没有直接帮助。

③ rust-anything（11-18） 说白了就是"搬家式重写"：不是一次性把老项目翻译成 Rust，而是先定接口，再一块一块搬，每搬一块就跑测试对答案。支持 TS/JS、Python、C、Go、Ruby、Java。它的价值是方法论——大型改造要可回滚、可验证、分步走。

④ BatteryHub（11-19） 350KB 的小工具，解决一个很具体的痛点：无线鼠标/键盘/耳机还剩多少电。C++/Win32 直调系统接口，不需要管理员权限，内存约 2MB。三天涨到 4k star，证明"小而准的工具"依然有市场。

⑤ SkillEvaluator（11-20，NVIDIA） 给 AI 技能做体检的流水线：能不能被发现、描述是否准确、调用是否稳定。属于 NVIDIA "Verified Skills" 体系的一环（Experimental）。对 DSH 最直接——我们装了 20 多个技能，正需要这种自动评测。

⑥ CLI-Anything（11-21） 一句话：给所有软件配一个"AI 能听懂的命令行翻译官"。每个软件生成一套统一命名的 CLI（cli-anything-xxx）+ 自动生成的 SKILL.md 说明书；一套 7 阶段生成器 + CLI-Hub 分发；2,461 个测试、18 个真实软件 Demo。本周已在本机装好，并挑了 5 个技能进 DSH。

⑦ firecrawl（11-22） 网页"榨汁机"：URL 进去，干净 Markdown 出来。三种形态（本机 Rust 单文件 / 云 / 自托管），能力是 Scrape/Crawl/Map/Search/Interact，firecrawl-local init 能自动注册成 MCP。本周已完成：装到本机 + 在 fakao-pwa 上线 /api/extract + 题目工坊单条/批量。

3) 横向对比与趋势

共性：一半项目在给"智能体"修基础设施。 SkillEvaluator（评质量）、CLI-Anything（供工具）、firecrawl（供数据）——三条加起来正好是"能力→质量→素材"的闭环。这说明 2026 年下半年的热点已经不是"再训一个模型"，而是"怎么让 agent 真正干成活"。

另一条线：极致的小而美。 abyssal-garden（96KB）、BatteryHub（350KB）都在证明——不靠堆资源，靠把一个问题想透。star 涨得都很快（1.7k～4k/几天），说明用户对"轻、快、不臃肿"极度买账。

技术栈偏好： TypeScript 仍是应用层主力；Rust 出现在两个位置（rust-anything 的重写目标、firecrawl 的本地版），说明"性能敏感 + 单文件分发"正在往 Rust 走；WebGPU 开始出现在个人项目里。

方法论趋势： 分步可验证（rust-anything）、统一契约（CLI-Anything 的命名与 SKILL.md）、可回滚改造——和我们自己的"改前先读、改后验证"是同一套思路。
