1) 项目是什么 / 解决什么问题

一句话：看任何网站 / App / 游戏是怎么做的，然后让 AI 给你复刻一个——一个开源的净室重建引擎（clean-room reverse engineering + rebuild）。

  • 指向一个目标，说"我想要什么"，它用真实检查工具研究原对象，让编码智能体生成一个新项目，再拿新项目与原对象逐项比对、迭代到"足够像"。
  • 100% Rust；自带解析器/反汇编器/反编译器（不依赖外部程序），装了 Ghidra 则额外用 Ghidra。
  • 为什么选它：它是 AI + 逆向 + 编程三条线的交汇点，且与 REA 同属"证据驱动、工具化"路数。

3) 核心机制与关键代码

A. 四步流水线：Study → Build → Check → Ready

  • Study（研究）：用真实检查工具研究原目标——网站：三种屏幕宽度截图、可见文字、量出的布局/颜色/字体/间距、展开菜单；App：窗口截图；Deep 模式才读代码/文件/JS。
  • Build（构建）：编码智能体按你指定的语言/框架/引擎（或合理默认）生成新项目。
  • Check（比对）：把新构建与原对象逐项比对，列出"还不像"的地方（网站比三种宽度、游戏跑自测、App 跑起来看行为）。
  • Ready（完成）：打开/试玩/预览，或继续改。

B. 净室(Clean room) vs 深挖(Deep)——最妙的设计

  • 净室（默认）：拒绝读取目标内部（代码/文件/页面源码），只靠"外部可观察"重建；越界工具会被拒绝并提示如何开 Deep。
  • Deep：全部工具放开，可读代码/文件/JS，装了 Ghidra 就用 Ghidra。
  • 把"合规/伦理"做成产品默认档位，而不是一句免责声明。

C. 证据优先，防 AI 瞎编

  • 每个结果都是带 confidence / coverage / limitations 的证据记录；大结果先给 summary，再用 core_evidence_browse 分页查看。
  • 320 个工具同时是 CLI 子命令和 MCP 工具 → App、CLI、任意智能体走同一套引擎，结果可复现。

D. 命令闸门

  • 构建安装依赖会真跑命令（npm/cargo…），对没见过的命令类型先弹"审批卡片"，可"本次允许/始终允许"。

4) 数据流 / 一次完整调用时序

craft-anything-cli rebuild https://example.com "Recreate this website"
  1. 建项目目录 Documents/Craft Anything/<proj>
  2. Study：截图/量布局/取证 → 写 investigation.cany/ 与 capture/
  3. Build：把证据喂给 Claude Code → 生成 app/
  4. Check：三宽度截图比对 → checks/ 里列出差异与相似度
  5. 未达标 → 带着差异回填再构建（轮次 --rounds）
  6. Ready：打开预览；"Make the header blue" 等增量修改

目录里 craft.json 记请求/目标/状态/历史，inbox/ 放待回答的问题——整个流程可审计、可续跑。

5) 关键难点与巧思

  1. 纯 Rust 自研反汇编/反编译器，不装 Ghidra 也能干一部分活（Ghidra 装了当增强）——跨平台一致、可编译 WASM。
  2. 一套工具三处复用（App/CLI/MCP），天然 agent-ready：每个工具都是子命令 + MCP 工具。
  3. 净室默认：把"只看可见、不碰源码"变成可强制执行的能力开关。
  4. 比对闭环（Check）：不是"生成完就算"，而是拿证据量化相似度再迭代。
  5. 证据账本：区分事实/置信度/局限，直接对抗大模型幻觉。

6) 如何自己复现 / 上手

# 需要 Rust >= 1.97
rustup update
git clone https://github.com/storytold/craft-anything && cd craft-anything
cargo run --release -p craft-anything          # 桌面 App
cargo install --path apps/craft-anything-cli    # 安装 CLI
craft-anything-cli doctor                       # 检查智能体/引擎是否就绪
craft-anything-cli rebuild https://example.com "Recreate this website"
  • 前提：本机要有一个登录好的编码智能体（默认 Claude Code，跑你自己的 claude，它不碰你的账号）。
  • 切模式：标题栏/设置，或 settings_set deep_mode true，或单次 --deep / --clean-room。
  • Linux 桌面还需 libxkbcommon / wayland / x11 / gtk3 等开发包。

7) 一句话总结

Craft Anything = 用"净室可观察 + 证据账本 + 编码智能体 + 比对闭环"，把"看懂一个软件并复刻它"做成可复现的四步流水线；纯 Rust、工具即 CLI/MCP，是该方向少见的工程化实现（早期 alpha，部分能力"已建未实测"，勿当成熟商用）。
