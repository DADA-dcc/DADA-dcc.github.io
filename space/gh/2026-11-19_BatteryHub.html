1) 它是干什么的（说白了）

在你的 Windows 任务栏上，直接显示无线鼠标、耳机、键盘、手柄还剩多少电。

就像在任务栏贴了一排小标签：🎧 30% 🖱 93%。低于 15% 变红，充电时旁边出现蓝色闪电，充满变绿色对勾。

它解决的问题：想知道罗技/雷蛇/海盗船的电量，通常得打开厂商那一大坨软件（G HUB、Synapse、iCUE…）。这个小工具不用装任何厂商软件，自己直接去问设备。

2) 它由哪几块组成（像一个"抄表员小队"）

BatteryHub.exe（一个 350KB 的小程序）
 ├─ 各品牌"抄表员"（src/drivers/）
 │    罗技、雷蛇、赛睿、海盗船、HyperX、PS/Xbox 手柄…
 │    每家按"厂商ID+产品ID"认设备，只发"只读"的电量查询
 ├─ 通用兜底（HID 电量 / 蓝牙 / XInput / HeadsetControl）
 │    厂商抄表员没认领的设备，才走这些通用办法
 ├─ 任务栏小挂件
 │    它不是普通窗口，而是"贴"在系统任务栏里的子窗口
 └─ 可选：电量历史（本地 TSV，最多 30 天）

3) 核心机制（它是怎么做到的）

A. 怎么"问"出电量？ - 每个品牌的设备都有一套自己的"暗号"（HID 报告格式），文档里根本没公开； - 项目按"厂商ID + 产品ID"认出设备，然后发一条只读的电量查询； - 不认识的设备，绝不乱写——这是它反复强调的安全底线。

B. 为什么能贴在任务栏上？ - 它找到 Windows 任务栏的内部窗口 Shell_TrayWnd，把自己的小窗口挂成它的子窗口，放在时钟左边； - 资源管理器重启了？它会自动重建。

C. 多设备怎么区分？ - 两个鼠标？图标角上会有 3 个字母的小标签（如 MX、PRO）； - 还能按品牌上色（雷蛇绿、HyperX 红…）。

D. 更新为什么"敢自动装"？ - 作者用自己的私钥给"校验清单"签名，公钥写死在程序里； - 下载的安装包 SHA-256 必须和签名清单一致才运行； - 就算有人盗了 GitHub 账号，也发不出能被自动安装的恶意更新。

4) 一次使用流程（像给设备"点名"）

  1. 下载安装包 → 一路下一步（不需要管理员）；
  2. 任务栏出现 🎧 30% 🖱 93%；
  3. 鼠标悬停看详情，点击出菜单（显示/隐藏设备、刷新、开机启动、退出）；
  4. 每 60 秒自动刷新一次；插电或电脑唤醒时立刻刷新；
  5. 想查历史：右键设备 → Battery history…（24 小时 / 7 天 / 30 天）。

命令行也好用：

BatteryHub.exe --list    # 列出所有设备和电量
BatteryHub.exe --json    # 输出 JSON，给脚本/状态栏用
BatteryHub.exe --dump    # 导出所有 HID/USB/蓝牙信息（提 issue 用）

5) 它比同类强在哪

  1. 极小：350KB / 2MB 内存，纯 Win32，无运行库、无后台服务；
  2. 不装厂商软件：直接跟设备说话，且只读；
  3. 覆盖面夸张：几百款设备、几十个品牌（README 里那张表长得吓人）；
  4. 更新链安全：签名校验清单 + 公钥内置，防账号被盗投毒；
  5. 诚实：专门列了"不支持/读不到"的设备与原因（如某些键盘固件根本不报电量）。

6) 你可以怎么玩

  • 普通用户：去 Releases 下 BatteryHub-Setup，安装即用；
  • 设备没被识别：菜单里点 Request support for a device…，它会生成一份报告（先给你看要发什么），提交后作者加支持；
  • 想改代码：需要 MinGW-w64，make 或 build.bat 即可构建。

给你的建议：如果你有罗技/雷蛇/手柄这类无线设备，装它比开厂商软件省事得多——尤其打游戏时任务栏一眼就能看到手柄电量。

7) 一句话总结

BatteryHub = 一个 350KB 的"任务栏抄表员"：按品牌暗号只读地问设备电量，不装厂商软件、不要管理员、还把更新链做成了签名验证。
